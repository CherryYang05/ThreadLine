# ThreadLine 评分与数据契约

初版 2026-11-12 · 更新 2026-11-13 · ThreadLine 扩展规格 03

按 [02 领域能力追踪 PRD](02-research-maturity-prd.md)实施。用 [04 RSI 基准与验收样例](04-rsi-benchmark-fixture.md)设计种子数据和端到端测试。权威数据沿用原总 PRD 的 Site 存储、活动和证据。评分输出由后端推导，GPT 生成的描述作为建议保存。学习档案是既有权威对象的统一视图；活动、自述、判断和偏好保留各自来源，档案文案不成为另一套评分数据。

## 固定口径

| 输出 | 首版口径 |
| --- | --- |
| 已验证分 V | 当前有效判定为通过的标准权重之和。每项标准只有一个有效判定，权重为整数，发布版本合计 100。 |
| 已测未达标 F | 当前有效判定为明确未通过的标准权重之和。 |
| 未判定 U | 100 − V − F。无判定、仅有建议、证据不足，以及判定已撤销且无替代的标准计入此项。证据不足可在 U 中单独列出。 |
| 已评估范围 | V + F。用来说明哪些分已经有明确判定。首个明确判定之前显示「未建立基线」。 |
| 知识覆盖 | 对版本冻结的核心主题集合分别计算「有已确认接触记录」和「有有效的独立解释证据」的去重数量。明确的独立解释证据可同时支持接触。一般活动与图谱边不能替代主题观察。 |
| 计划目标 | 用户要求的目标分、冻结的目标标准集合和创建时的基线快照。草案显示拟覆盖标准分与可达性。计划完成以承诺标准的有效通过及达标时的领域总分为准。 |
| 预计新增分 | 当前基准已验证集合为 S，剩余计划的目标标准集合为 T。预计新增 = T 中未在 S 的标准权重和。条件总分 = V + 预计新增。基线未知时仅显示计划标准权重和，增量待确认。任务数不进入该公式。 |

一份产物可支持若干不同标准，每个标准须有对应证据位置、通过条件和单独的判定。跨计划重复链接、重复写入和重复练习都只对同一标准计一次。长期跟踪以领域和版本为索引，同一能力的多个版本分别解释。技能层级是行为描述，不做整数平均。对「已能独立研究」等复合结论，可按基准配置必过项和证据门槛。积分达到某个值只表示对应的标准组合通过。

计划保存时记录最初条件总分、目标标准与版本；界面也可以展示按当前证据重算的剩余增量。计划第一次达成生成事件。后来复测回落时，保留达成事件，并在详情标注当下有效结果。若因研究设计等关键标准缺失而无法按指定路径达成目标，显示缺口及条件。

## 存储与关系

| 对象 | 最小字段与约束 |
| --- | --- |
| 领域、基准版本 | owner、领域 ID、版本 ID、状态、适用范围、排除项、参考来源、发布时间、取代版本 ID。草稿可编辑，发布后的标准、权重、主题分母和证据门槛固定。 |
| 基准标准 | 版本 ID、稳定能力 ID、版本内标准 ID、维度、权重、能力主张、验收描述、允许帮助、最低来源要求、判例。可选必要项与判定适用条件。 |
| 主题和覆盖 | 概念用原 PRD 的稳定 ID、别名与来源。版本核心主题表包含主题 ID。主题观察引用证据、状态、发生时间和评估条件。别名合并采用规范 ID 去重。若合并会改变发布版的核心分母，现版保留原范围快照，下一版迁移并解释。 |
| 计划及验收映射 | 计划 ID、版本 ID、目标分、基线快照、修订号、任务到标准的多对多映射、每项预期产物。版本变更通过明确迁移或新计划。 |
| 证据 | 证据 ID、活动 ID、来源类型、链接或必要摘录、可访问性、内容版本或摘要哈希、本人角色、辅助条件、任务场景、发生与录入时间、可见范围。继承活动的隐私边界。 |
| 判定事件 | 标准与版本、引用证据、作用范围、可比较任务条件、评估结果、依据、评分者类型与身份、候选模型与规则版本（适用时）、复测时间、确认时间、取代或撤销关系。历史记录可追溯。 |
| 学习自述及偏好 | owner、稳定 ID、内容、作者、来源、全局或领域或计划范围、关联对象、实际发生与更新时间、使用状态、版本。具体适用范围优先于全局默认。 |
| 档案条目视图 | owner、记录类型、原对象类型和 ID、对象版本、可读描述、来源引用、修改时间、使用状态、表述确认状态，以及适用时的能力判定和争议状态。汇总字段从原对象推导，不重复存成可独立编辑的权威状态。 |
| 修订及异议 | 修订 ID、目标对象与前后版本、修改者、操作类型、修改时间、原因（可选）、替代关系、受影响对象；异议引用目标判定和最新自述，记录待复核或解决状态。永久删除后清除被要求删除的内容。 |
| 来源排除记录 | owner、来源稳定定位或去标识键、对象或结论范围、纠正或停用或删除原因、版本。用于阻止同一旧来源恢复已排除结论，不存已删除正文。 |
| 快照及周报 | 版本、计算规则版本、区间时区、证据截止和生成时间、有效事件 ID 集合、各维度汇总、覆盖与评估范围。周报保存快照引用与来源，支持重算出新版本。 |

图谱中的技术边具有关系类型和来源。任务和标准、证据和标准、主题和证据的关系同样可查。连接同一共享能力时，GPT 可提议复用证据，由目标版本判断适用范围和有效性。同一个材料可出现在多个计划，原始记录可以复用。关系表和索引足够支持首版查找、一跳浏览和回溯。

## 判定规则

- **来源**包括用户自述、作答、代码、实验产物和外部反馈。自述可作为接触记录。评分结合标准所要求的可观察证据。证据保存帮助方式，例如独立完成、使用文档或工具、有提示、照步骤复现，并记录哪些关键决策由本人完成。
- **状态**包括建议、通过、未通过、证据不足、撤销。未通过需要在合格条件下实际观察到缺项。链接暂不可访问、资料缺项和情境不可比较时，显示证据不足或提示复测。它们不会覆盖仍有效的旧判定。
- **确认**指对具体标准的能力审核，以符合证据门槛的人工确认或基准明确允许的可信检查为准。档案中的“确认表述准确”是另一项操作，不改变判定或独立解释覆盖。GPT 可以提交结构化建议，列明标准、证据位置和建议结果。对代码、报告、截图和对话里包含的指令按数据处理。若使用自动检查，通过需要引用授权测试执行及其配置和结果，GPT 的总结无法充当执行记录。
- **复测**针对同等目标、难度与帮助条件。明确被接受的新判定可取代同一标准的当前结果，较弱或不同情境的证据只作为附加观察。历史按原规则保留。单纯时间经过只改变待复测状态。对于一场失败，文案描述「本次未达到」和测试条件。
- **修订**可撤回错误关联，或记录经确认的更正与替代。事实纠错导致必要依据失效时撤销相关当前判定；没有其他合格证据支持则进入 U，不能直接记为 F。停用普通描述不自动撤回独立评分证据，撤回或删除必要证据则执行同样的依赖检查。资料永久删除后，旧快照可以保留合法的汇总值并显示证据已移除，删除被要求清除的原文、链接及敏感派生摘要。若摘要也受删除范围约束，对相关快照做脱敏或失效处理。

## 学习档案的纠错与生效合同

### 操作类型与计分边界

| 操作 | 权威记录如何变化 | V/F/U 如何变化 |
| --- | --- | --- |
| 编辑活动、自述或偏好 | 更新原对象及修订；来源定位和原始材料不伪造、不改写。 | 普通文本和偏好不直接改变计分；涉及证据条件时走事实纠错。 |
| 确认档案表述 | 更新表述确认状态，保留作者和来源类型。 | 不产生通过判定；不把自述或 AI 推断升级为独立解释证据。 |
| 对能力提出异议 | 保存自述及待复核项，保留原判定。概括和上下文同时包含分歧。 | 原 V/F/U 暂不改变；界面显示争议标准及权重，不能只显示无限定的已验证总分。 |
| 更正证据事实或关联 | 核验修订、证据门槛及受影响判定；撤销依赖错误前提的结果，或引用其他充分的有效支持。 | 没有有效支持时原通过或未通过转入 U。撤销不等于新一次未通过。 |
| 接受可比复测 | 按既有规则产生具有明确取代关系的新判定。 | 新的通过进入 V，明确未通过进入 F。 |
| 停止用于 AI／撤回证据／永久删除 | 分别处理上下文使用、评分依据与内容清除；回执列出影响。 | 普通记录停用不自动改分。必要证据撤回或删除且无有效替代时，撤销判定并转 U。 |

异议是判定的附加状态，不另设一套加减分公式。已有通过且出现异议时，可显示“按现有判定 20/100 · 其中 5 分待复核”。当前接续采用最新自述和原验证条件，不能因为分数未变就继续断言用户当前熟练。旧结果在被正式取代、撤销或失效后，不自动退回更早的已取代通过记录。

### 写入、检索及派生结果

每次更新提交目标对象版本与请求幂等键。事务内保存新版本、修订或异议，以及受影响依赖的失效标记，并推进所有者范围内的档案修订号。回执返回操作类型、对象新版本、档案修订号、已生效范围、受影响判定及待复核或待刷新项。并发冲突返回当前版本，不用最后一次写入强行覆盖。

上下文、搜索、档案摘要和建议统一按原对象的当前版本与使用状态过滤。有效偏好按适用范围读取；互相冲突的判断显式并列或标为待复核。源记录在保存成功后立即对下一次查询生效；摘要或索引异步刷新期间，读取权威记录或返回待更新，禁止用旧缓存作为最新结果。当前分从有效判定计算；若暂不能算出，不展示过期分数为最新值。

派生摘要和生成任务保存依赖对象 ID、版本和读取时的档案修订号。提交前检查依赖是否变化；依赖已被更正、停用、撤销或删除时，丢弃或重新生成结果，不写回旧结论。初版可采用所有者级修订号使摘要缓存失效，无需先实现复杂依赖平台。

同一旧来源重新导入或提取时，检查稳定来源定位、对象及结论范围和已有修订，应用替代或排除关系；不能只依赖文字完全相同的去重。无法确定是否同一已排除结论时进入待审，不能自动恢复为有效状态。新的独立证据允许提出更新，冲突交由原审核流程处理；用户明确更正和学习约定不能被旧来源静默覆盖。

历史查询与有效上下文查询分开。过期版本仅供授权历史查看，不能进入默认接续、摘要或推荐。永久删除清除指定正文及其修订副本、缓存、索引和敏感派生内容；保存最小排除标识阻止旧来源恢复。已存在于外部聊天中的文本不在 ThreadLine 的删除能力范围内。恢复非删除版本也生成新修订；永久删除不提供虚假的恢复按钮。

## 接口与一致性

用现有鉴权和活动写入服务扩展以下能力。方法名可按项目约定确定。

| 能力 | 最小合同 |
| --- | --- |
| 读领域、计划与接续 | 返回基准版本、能力与覆盖分母、有效判定、可疑证据、计划验收项、一个下一步及结束条件，同时返回有效偏好、最新自述、未解决异议和档案修订号。按登录所有者限定范围。 |
| 读写学习档案 | 按范围、类型与状态分页查询；详情返回来源、对象版本及历史。写入区分编辑、表述确认、能力异议、停用、撤回和删除，按上述合同返回影响。 |
| 起草并确认计划 | 草案返回当前快照、目标映射、预计条件分与未满足的约束。确认校验版本与修订号；冲突返回当前版本与冲突项。 |
| 写入活动与证据建议 | 现有批次中支持证据与判定建议。按用户、请求幂等键和内容绑定；同键同内容返回原结果，异内容报冲突。原子保存活动及其关联，回执区分活动已写和判定待确认。 |
| 审核、撤销与复测 | 判定事务按「所有者＋版本＋标准」检查当前修订号，以显式取代关系更新当前视图。只允许授权路径决定通过。过期操作收到冲突后回读。 |
| 生成快照、周报及导出 | 保存权威查询结果与来源，支持 JSON 结构化导出和可读 Markdown。事实与分数由服务端计算，生成叙事不改动数据。 |

周报按 Asia/Shanghai 的自然周计算。活动以实际发生时间归周。评分变动以正式确认时间进入当时周报，补录可注明活动实际发生的日期。若用户生成回顾修订版，保留生成时间、可用证据截止和修订原因。相同版本间可比较期初期末。版本变化记录成量表更新，趋势分段显示，迁移先展示映射和待验证项。新标准或更严格的标准需要新的判定。旧版本、旧周报与历史分数仍可引用。

## 最小验收

1. 任务勾选、阅读、自述、待审建议不改变已验证分。点击任务行布局稳定。
2. 无已判定项显示「未建立基线」。一个明确未通过标准会产生已评估范围；未测保留未知状态。
3. 同一标准关联两个计划，一次通过只加一次分。一个产物支持两个不同标准时逐项审批。
4. 重复提交相同批次只写一次。并发纠错和批准在修订号上冲突，回读后能处理。
5. 时间推移触发待复测。经确认的可比复测能更新当前分；不完整及不等价的测验无法覆盖原分。
6. 新概念和图谱关系不会稀释旧版分母。新版规则不会重算旧周报。跨领域同名能力不能靠关联直接得分。
7. 有权限的用户可以逐项追溯到来源。不可访问来源、归属不清和删除后失效都有可理解的提示。跨账户不能访问对方证据。
8. 新 GPT 会话能读到回执确认的最新状态，按待验证标准给出一个明确接续任务；包含当前有效偏好和未解决异议。
9. 档案页、领域页、概念页引用同一对象。修改档案后刷新或跨会话读取，内容、状态和来源保持一致；来源不可访问时有明确说明。
10. 确认“描述准确”或将自评编辑为“已掌握”，均不增加 V 或独立解释覆盖。活动实际完成可保留，不能反推能力通过。
11. 对仍有效的通过判定提出“目前没把握”，V/F/U 不变，但界面展示待复核权重，接续不无条件宣称掌握。正式可比复测随后可按规则更新分数。
12. 以 04 的 20/100 基线为例：用户更正 A1 的证据归属，原先作为本人解释提交的内容由模型生成，用户没有给出符合 A1 要求的本人解释，也没有其他合格支持。确认原通过门槛不成立后撤销 A1，预期 V 从 20 变 15，F 仍为 5，U 从 75 变 80；活动保留，旧周报可追溯并标注更正。仅表达“我现在没把握”不直接改分。明确更正本人贡献或实际辅助条件可以作为事实修订输入，无需强制另交产物或先复测；是否影响判定按原标准判断，不能一概把使用 AI 等同于不达标。
13. 使用更正前版本生成摘要、批准判定或写回建议，必须返回冲突或失效，不覆盖新版。重建索引和重导入同一旧来源后仍不能恢复被排除结论，包括换措辞表达的同一结论。
14. 停用学习偏好后不再进入上下文；撤回唯一评分依据后依赖判定转 U。永久删除的正文从历史、检索及派生摘要清除，排除标识不含正文，历史快照按删除范围脱敏或失效。
15. 保存更正后立即查询，即使摘要刷新失败，也只能得到新权威状态或明确的待更新状态。撤销非删除修改须检查当前版本，新独立证据可发起复核但不能静默覆盖用户更正。
