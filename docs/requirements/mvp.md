# 首版需求梳理

状态：根据项目讨论与最新需求变更摘要整理，待核对三份 PRD 正文。本文用于对齐范围，不替代原始 PRD 或正式数据契约。[来源与完整性](sources.md)。

## 目标与核心流程

让用户在持续的学习项目中，保留可信的进度和接续点，查看并纠正 ThreadLine 对自己的记录。

一次完整流程是：恢复目标和接续点 → 学习或完成项目任务 → 记录实际活动及证据 → 查看或更正档案 → 在新会话中继续。

## 当前首版范围

| 能力 | 可观察的行为 | 依据 |
| --- | --- | --- |
| 计划、任务与活动记录 | 分别记录目标、待办和实际发生的活动；完成任务不自动产生能力结论 | 项目讨论对原 PRD 的描述，细节待核对 |
| 跨会话接续 | 恢复当前目标、任务、卡点、下一步和停止条件；缺少信息时保留未知 | 项目讨论对原 PRD 的描述，细节待核对 |
| 学习档案 | 提供独立入口，按当前项目或领域查看记录、来源和历史，支持编辑或提出异议 | 最新需求变更摘要明确列入 P0 |
| 更正生效 | 保存后的更正影响后续读取，旧资料或晚到任务不会把错误写回来 | 最新需求变更摘要 |
| 保存回执 | 说明哪些更正已生效，以及哪些关联能力判断需要复核 | 最新需求变更摘要 |

事实型周报、概念局部关系和完整能力追踪在讨论中出现过；本次将其放入后续实施建议，具体阶段以原 PRD 核对结果为准。

## 学习档案

默认围绕当前项目或学习领域展示，也应能查找 ThreadLine 实际长期保存、用于个性化学习的其他记录。

| 记录类型 | 示例（合成） | 可进行的操作 |
| --- | --- | --- |
| 学习活动 | 完成一次流水线并行练习 | 更正内容、日期、关联任务及完成情况 |
| 用户自述与自评 | 理解 PP 的用途，还不能独立推演 1F1B 调度 | 直接编辑、补充 |
| 系统学习判断 | 某次练习中能独立解释，但尚未验证变式应用 | 查看依据，纠正提取错误，提出异议或补证据 |
| 学习偏好与接续约定 | 先完成当前主线；下次提高练习难度 | 修改、停用并明确适用范围 |

每条记录可展开查看来源、更新时间、修改者、关联对象和修改历史。档案页展示 ThreadLine 保存的数据，不能宣称展示 ChatGPT 的全部记忆或未接入的历史会话。

## 更正与能力判断

1. 档案页与 AI 使用同一份记录，编辑更新原有对象，关联页面同步反映有效状态。
2. 用户已保存的更正须抵御旧会话重导入、旧摘要再生成、后台任务晚到及并发旧版本写入。
3. 用户确认一段记录准确，只能说明表述被确认，不能代替能力验证。
4. 用户自评“还没把握”时，记录异议并影响学习安排，可建议复测；不能据此直接升降分。
5. 如果原判定依赖的证据被确认无效，应复核关联判断；缺少其他有效依据时可退回未判定，同时保留真实活动。
6. AI 辅助是否允许，依据具体能力标准；不能把所有 AI 辅助一概视为无效，也不能默认其证明独立完成。

完整评分需要核对领域基准版本、有效证据和计算契约。没有观察的数据应保持未判定。不能从对话印象、活动次数或时间间隔推算能力百分比。

## 验收场景草案

以下由摘要中的行为要求转成验收示例，尚未执行。数据均为合成示例。

| 编号 | 操作与前提 | 预期结果 |
| --- | --- | --- |
| AC-01 | 打开项目的学习档案 | 可查看四类记录及来源、更新时间、修改者、关联对象和历史 |
| AC-02 | 将“已掌握 PP”更正为“理解用途，尚不能独立推演 1F1B”后开启新会话 | 接续读取更正后的状态，保留待验证部分并调整下一步；原活动仍存在 |
| AC-03 | 更正后重导入原会话或让旧摘要任务完成 | 不覆盖更正；系统能说明旧写入未生效或需要处理冲突 |
| AC-04 | 两个编辑者基于同一旧版本保存不同内容 | 不静默丢失已保存的更正，返回可处理的冲突信息 |
| AC-05 | 用户只表达“我还没把握”，未否定既有证据 | 记录异议、调整后续练习安排；分数不因自评直接变化 |
| AC-06 | 确认“本人独立解释”的唯一证据实际为 AI 生成，未包含用户解释 | 复核关联判断；无其他依据时退回未判定，保留真实学习活动 |
| AC-07 | 用户确认“记录准确” | 记录表述确认，不自动标记能力通过或新增得分 |
| AC-08 | 保存更正，存在尚待复核的关联判断 | 回执区分已生效记录与待复核判断；后续接续不继续断言有争议的结论 |
| AC-09 | 开始时读取接续点，结束记录后再次继续 | 当前目标、卡点、下一步与停止条件一致；缺少的数据明确显示未知 |

## 仍需原文核对

- 计划、任务、活动、证据和档案记录的完整字段、状态、关联约束及权限。
- 历史版本保留、导出、删除与引用失效规则。
- 写入协议、冲突响应、幂等范围和关联复核的完成条件。
- 领域能力基准、评分公式、AI 辅助规则，以及周报与图谱的具体交付阶段。
