# 开发入门

当前仓库已准备文档、协作模板和自动检查，应用开发尚未开始。Python 只用于仓库检查，不代表已确定应用技术栈。

## 环境与首次检查

需要 Git 和 Python 3.10 或更新版本。检出包含本文件的分支后，在仓库根目录运行：

```sh
python3 scripts/check_repository.py
```

检查脚本只使用 Python 标准库，无需安装第三方包，也不会访问网络或更改文件。提交前再执行：

```sh
git diff --check
git diff --cached --check
```

GitHub 的 Repository checks 工作流在 Pull Request 更新和默认分支 master 收到提交时运行相同的 Python 命令。它检查文本编码、换行、行末空白和 Markdown 中的本地文件链接。Markdown 标题锚点、外部网址及 YAML 语法不在自动检查范围内；修改 Issue 表单或工作流时需另行核对。

## 开始下一个开发任务

1. 阅读 [Agent 开发约定](../../AGENTS.md)、[首版需求](../requirements/mvp.md) 与[需求来源](../requirements/sources.md)。
2. 获取相关 PRD 正文，核对该任务涉及的需求；资料仍不完整时，明确记录假设和待核对项。
3. 选择一项验收场景，并在独立分支实现。涉及状态写入时，覆盖重复请求、旧版本和并发冲突。
4. 按实际代码引入运行、测试与构建命令，再更新本指南。当前没有应用启动命令。
